# 🦷 Doctor Dentist

A modern and responsive **Dental Hospital Website** built with pure web technologies.  
Designed with a clean interface, responsive layout, and dedicated legal pages.

---

## ✨ Features

- Modern and responsive UI
- Dental hospital landing page
- Responsive navigation
- Clean and semantic HTML5
- Custom CSS3 styling
- Vanilla JavaScript interactions
- Privacy Policy
- Terms of Services
- Mobile-friendly design
- Lightweight and dependency-free

---

## 🛠️ Technologies

| Technology | Usage |
|---|---|
| HTML5 | Structure & semantics |
| CSS3 | Styling & responsive design |
| Vanilla JavaScript | Interactions & functionality |

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/adil-12-hassan/Doctor-Dentist.git
```

Open the project directory:

```bash
cd Doctor-Dentist
```

Then open:

```text
index.html
```

in your browser.

No build tools, package manager, or external dependencies are required.
