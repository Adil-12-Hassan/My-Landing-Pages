# Calculator

A clean, responsive, and lightweight calculator built with **HTML5, CSS3, and Vanilla JavaScript**.

Designed with a simple interface, keyboard support, calculation history, and responsive behavior for both desktop and mobile devices.

## ✨ Features

* ➕ Basic arithmetic operations
* Addition
* Subtraction
* Multiplication
* Division
* `%` Percentage calculation
* ⌨️ Full keyboard support
* 🕘 Calculation history for recent results
* 📱 Responsive design for desktop and mobile screens
* ⚠️ Division-by-zero error handling
* 🚀 No frameworks, libraries, or build tools required
* 🌐 Runs directly in any modern web browser

## 🎮 Usage

You can use the calculator through the on-screen controls or your keyboard.

| Key                 | Action                |
| ---------- | --- |
| `0-9`               | Enter numbers         |
| `+`                 | Addition              |
| `-`                 | Subtraction           |
| `*`                 | Multiplication        |
| `/`                 | Division              |
| `%`                 | Percentage            |
| `Enter` / `=`       | Calculate result      |
| `Backspace`         | Delete the last input |
| `Delete` / `Escape` | Clear calculator      |

### Run Locally

No installation or setup is required.

1. Clone the repository:

```bash
git clone <https://github.com/Adil-12-Hassan/Hassan-Calculator.git>
```

2. Open the project directory:

```bash
cd calculator
```

3. Open `index.html` in your preferred modern browser.

That's it. No dependencies or build process are required.
