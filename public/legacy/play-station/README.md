# Audio Workstation Pro

**Audio Workstation Pro** is a personal web-based audio analysis, conversion, and editing application.

Live application: https://play-station-mu.vercel.app/

## Overview

This project provides a browser-based workspace for working with audio files. The current application includes tools for:

- Audio file upload and playback
- Waveform and pitch analysis
- Pitch analysis
- Audio format conversion
- MP3, WAV, OGG, M4A, AAC, FLAC, and AIFF format support
- Audio trimming
- Audio normalization
- Fade in and fade out
- Audio reversal
- Bass boost
- Treble boost
- Volume adjustment
- Playback speed adjustment
- Video-to-audio extraction functionality
