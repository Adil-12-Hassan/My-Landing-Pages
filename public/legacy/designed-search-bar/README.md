# 🚀 Animated Search Bar

A modern, minimal, and interactive **search bar UI** built using pure **HTML & CSS**.  

This project demonstrates smooth animations and creative UI design without using JavaScript.

---

## ✨ Features
- 🎯 Built with pure HTML & CSS
- 🔍 Animated search icon transformation
- ⚡ Smooth expanding input effect
- 📱 Fully responsive (mobile optimized)
- 🌐 Integrated with Google Search

---

## 🎥 Preview

The search bar starts as a circular button and smoothly expands into a full input field when focused.

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
  - Flexbox
  - Transitions
  - Pseudo-elements (`::before`, `::after`)

---

## 📂 Project Structure
- index.html 

---

## ⚙️ How It Works
- The search icon is created using CSS pseudo-elements.
- When the input is focused:
  - The input field expands smoothly
  - The search icon transforms into a close-style shape
- The form sends search queries directly to **Google**
